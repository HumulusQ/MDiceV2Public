## 🚀 使用流程

### 用户使用流程

```
1. 打开CustomizedReply面板
   ↓
2. 选择要编辑的回复规则
   ↓
3. 点击脚本编辑模式切换按钮
   ↓
4. 选择编辑脚本的方式：
   ├─ 直接在编辑框输入脚本代码
   │  └─ 定义 function MainProcess() ... end
   │
   └─ 从文件加载已有脚本
      ├─ 点击"从文件加载 Lua 脚本"
      ├─ 选择.lua文件
      └─ 文件内容自动加载
   ↓
5. 保存规则（脚本内容自动保存）
   ↓
6. 消息触发规则时，脚本自动执行
   ├─ MainProcess() 被调用
   ├─ 获取脚本返回值
   ├─ 替换<output>标签
   └─ 发送最终回复
```

### 脚本编写流程

```
1. 了解脚本上下文变量
   ├─ user_id, user_name
   ├─ group_id, group_name
   ├─ message, default_reply
   ├─ timestamp, is_ated
   └─ custom_data

2. 编写 MainProcess() 函数
   ├─ 接收上下文变量（通过全局变量）
   ├─ 实现业务逻辑
   └─ 返回回复字符串

3. 处理 <output> 标签
   ├─ 如果有<output>标签，替换为脚本返回值
   └─ 如果没有，脚本返回值直接作为回复

4. 测试和调试
   ├─ 在编辑框中输入脚本
   ├─ 查看执行结果
   └─ 根据结果调整脚本
```
