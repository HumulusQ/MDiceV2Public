## 🎮 功能实现细节

### 1. 脚本编辑模式切换

**实现方式**:
- ToggleButton绑定到IsScriptEditMode属性
- UI自动根据该属性显示/隐藏相应控件
- 普通模式和脚本模式TextBox互斥显示

**交互流程**:
```
用户点击按钮 → IsScriptEditMode翻转 
  → UI自动刷新 → 显示/隐藏脚本编辑区域
```

### 2. 脚本文件加载

**实现方式**:
- OpenFileDialog支持.lua文件选择
- 异步读取文件内容
- 自动填充ScriptContent属性

**交互流程**:
```
点击按钮 → 打开文件对话框 → 选择.lua文件
  → 异步读取文件 → 更新ScriptContent
  → UI自动显示文件名和icon
```

### 3. 脚本执行框架

**实现方式**:
- ScriptExecutor类负责脚本执行
- 创建ScriptContext传递上下文信息
- MainProcess函数是脚本入口
- 异常时返回原始回复（降级处理）

**执行流程**:
```
规则匹配 → 检查IsScriptEditMode
  → 是: 创建ScriptContext → 执行脚本 → 替换<output> → 发送回复
  → 否: 使用默认回复列表 → 随机选择 → 发送回复
```
