# 💕 机器人投喂脚本 - 完整使用指南

## 📋 快速开始

### 1. 脚本文件
脚本路径：`Mods/CustomizedReply/scripts/feedpet.lua`

### 2. 核心概念

这是一个"投喂机器人"系统，将机器人拟人化为一个需要好感度的角色：
- 💝 **投喂** = 表达对机器人的喜爱
- 💗 **好感度** = 机器人对用户的好感程度
- 💬 **对话** = 根据好感度做出不同的反应

---

### 3. 可用函数

| 函数名 | 功能描述 | 返回值 |
|--------|--------|--------|
| `MainProcess()` | 投喂机器人，随机增加 1-50 好感度 | 投喂反馈消息 |
| `QueryAffinity()` | 查询机器人对你的好感度 | 好感度信息 |
| `TalkToBot()` | 和机器人对话（根据好感度变化） | 拟人化对话 |
| `ResetAffinity()` | 重置好感度为初始值 100 | 重置确认消息 |
| `SetAffinity(value)` | 手动设置好感度（调试用） | 设置确认消息 |

## 💾 数据存储详情

### 存储位置
- 所有好感度数据存储在 **Mod 全局存储** 中
- 每个用户数据独立存储

### 存储格式
```
键：bot_affinity_{user_id}
值：数字字符串（如 "245"）
```

### 示例
```
bot_affinity_123456789 = "245"  // 用户 123456789 的好感度
bot_affinity_987654321 = "500"  // 用户 987654321 的好感度（满）
bot_affinity_111111111 = "30"   // 用户 111111111 的好感度（低）
```

## 🐛 故障排除

### 问题 1: 脚本执行失败，显示 "[脚本错误]"
**解决方案**：
- 检查好感度键是否为 `bot_affinity_{user_id}` 格式
- 确认 `mod_storage_read/write` 函数可用
- 查看详细日志了解具体错误

### 问题 2: 好感度每次增加不同
**原因**：这是正常行为，脚本设计为随机增加 1-50

**如需固定增加值**：修改脚本中的：
```lua
-- 原来: 
local growth_value = math.random(1, 50)

-- 改为:
local growth_value = 10  -- 每次增加 10
```

### 问题 3: 对话总是同一个
**原因**：`TalkToBot()` 会从对应等级的对话库随机选择

**验证**：多次调用 `TalkToBot()` 查看是否变化
