# 可持续叙事运行时架构 (Sustainable Narrative Runtime)

## 架构概览

从"长期记忆聊天机器人"进化为"可持续叙事运行时"。

## 核心层

### 1. Runtime Core（运行时核心）
- **职责**：系统入口，协调各层工作
- **组件**：
  - `AiCharacterSession` - 角色会话管理
  - `TrpgContextPipeline` - 上下文构建管道
  - `PromptAssembler` - Prompt 组装器
  - `PostProcessor` - 响应后处理器
  - `BackgroundMaintenanceLoop` - 后台维护循环

### 2. EventLog（不可变事件日志）
- **职责**：单一真相来源，所有状态重建的基础
- **特性**：
  - 不可变写入
  - 因果链追踪（`Consequences` 字段）
  - 事件回放验证
- **组件**：`EventLog.cs`

### 3. Timeline（时间轴）
- **职责**：管理时间流，解决时间碎片化
- **子层**：
  - **Story Spine** - 极简主线时间轴（`StorySpine.cs`）
  - **Hierarchical Timeline** - 分层时间轴结构（`HierarchicalTimeline.cs`）
  - **Temporal Layering** - 时间分层存储（`TemporalLayering.cs`）

### 4. Entities（实体层）
- **职责**：管理实体身份，防止 NPC 漂移
- **组件**：`EntityCanonicalizer.cs`
- **特性**：
  - 身份规范化
  - 别名管理
  - 身份合并

### 5. Scenes（场景层）
- **职责**：管理场景状态和快照
- **组件**：`SceneSnapshotManager.cs`
- **特性**：
  - 场景快照
  - 场景状态追踪

### 6. Objectives（目标层）
- **职责**：管理角色目标
- **组件**：`ObjectiveLayer.cs`
- **特性**：
  - 目标添加/完成/放弃
  - 目标优先级

## 投影层

### 7. Projection Layer（投影层）
- **职责**：从 EventLog 投影当前世界状态
- **组件**：`WorldStateProjection.cs`
- **投影内容**：
  - 实体状态（`EntityState`）
  - 物品状态（`ItemState`）
  - 场景状态（`ProjectedSceneState`）

## 记忆层

### 8. Episodic（情景记忆）
- **职责**：角色情景记忆，记忆真相来源
- **组件**：`EpisodicMemory.cs`
- **特性**：
  - 角色特定记忆
  - 记忆类型（情景、语义、怀疑、情绪、谣言、错误信念）
  - 遗忘机制
  - 世界观重建

### 9. Semantic（语义记忆）
- **职责**：语义索引，用于检索
- **组件**：`MemoryNode`（在 `ChatDatabase.cs` 中）
- **特性**：
  - 语义相似度检索
  - embedding 向量
  - 关键词索引
- **定位**：NOT 记忆真相，仅作为检索索引

### 10. Narrative（叙事层）
- **职责**：管理叙事结构和因果关系
- **组件**：
  - `CausalGraph.cs` - 因果图谱
  - `NarrativeEntropyManager.cs` - 叙事熵管理
- **特性**：
  - 因果链追踪
  - 伏笔连接
  - 边衰减
  - 熵管理（事件老化、弧压缩、实体聚合、历史蒸馏）

### 11. Relationship（关系层）
- **职责**：管理实体间关系
- **特性**：
  - 关系追踪
  - 关系变化检测

## 检索层

### 12. Retrieval Layer（检索层）
- **职责**：语义检索和相关性排序
- **组件**：
  - `VectorSearch.cs` - 向量检索
  - `SalienceRanking.cs` - 重要性排序
  - `TokenBudgeting.cs` - Token 预算
- **技术**：
  - embedding 向量化
  - MMR（Maximal Marginal Relevance）去重
  - semantic recall 语义召回
  - 重要性排序（目标、伏笔、实体、时间相关性）

## AI 层

### 13. AI Layer（AI 层）
- **职责**：角色扮演、决策、表达
- **组件**：
  - 外部 AI 模型调用
  - `RuntimeValidator.cs` - 运行时验证
- **功能**：
  - 角色扮演
  - 决策制定
  - 表达生成
  - 标签解析（`<objective>`, `<event>`, `<memory>` 等）

## 数据流

```
用户输入
  ↓
Runtime Core
  ↓
EventLog（写入事件）
  ↓
Timeline（更新时间轴）
  ↓
Entities/Scenes/Objectives（更新状态）
  ↓
Projection Layer（投影当前状态）
  ↓
Episodic（生成角色记忆）
  ↓
Semantic（更新语义索引）
  ↓
Narrative（更新因果图谱）
  ↓
Retrieval Layer（检索相关内容）
  ↓
AI Layer（生成响应）
  ↓
PostProcessor（处理标签）
  ↓
用户输出
```

## 关键设计原则

### 1. 单一真相来源
- EventLog 是所有状态重建的唯一事实来源
- EpisodicMemory 是角色记忆的唯一真相来源
- MemoryNode 仅作为语义索引，不作为记忆真相

### 2. 不可变事件溯源
- 所有状态变更通过事件记录
- 状态通过事件回放重建
- 因果链通过 `Consequences` 字段追踪

### 3. 分层时间管理
- Story Spine：极简主线
- Hierarchical Timeline：分层结构
- Temporal Layering：时间分层存储

### 4. 动态熵管理
- Event Aging：旧事件压缩
- Edge Decay：弱关联衰减
- Arc Consolidation：剧情弧折叠
- Entity Consolidation：低活跃实体聚合
- Historical Distillation：历史转化为世界事实

### 5. 智能检索
- embedding 向量化
- MMR 去重
- Salience Ranking 重要性排序
- Token Budgeting 动态预算

## 系统演进

### 从：
🧩 "长期记忆聊天机器人"

### 到：
🌌 "可持续叙事运行时"

### 关键变化：
1. **记忆系统重构**：MemoryNode 从记忆真相改为语义索引
2. **分层架构**：明确的层职责划分
3. **事件溯源**：所有状态基于不可变事件日志
4. **时间管理**：分层时间轴解决时间碎片化
5. **叙事管理**：因果图谱和熵管理维持叙事连贯性
6. **智能检索**：embedding + MMR + Salience Ranking
