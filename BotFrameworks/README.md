# Optional QQ runtimes

This directory is included in MDiceV2 release packages, but it does not ship SnowLuma or NapCat binaries.

Open MDiceV2's **Main Panel**, hover the `+` tab on the right, and choose **SnowLuma** or **NapCat**. MDiceV2 shows the upstream notice and downloads the selected official Windows x64 release only after the user confirms.

Downloaded files are stored under `BotFrameworks/<framework>/runtime/`. MDiceV2 starts the selected runtime, waits for its QQ account to log in, then connects to its local OneBot v11 WebSocket automatically.

The selected runtime remains a separate third-party program. Its licence, privacy policy, account-risk notice, and login requirements apply.
